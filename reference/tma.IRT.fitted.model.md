# Example `blavaan` fitted object

A fitted `blavaan` object from a unidimensional two-parameter IRT model,
included as example data for demonstrating
[`BayesIRTplot()`](BayesIRTplot.md).

## Usage

``` r
tma.IRT.fitted.model
```

## Format

A fitted model object of class `blavaan`.

## Source

Item Response Warehouse: <https://itemresponsewarehouse.org/data.html>

## Details

The model was fit using the `blavaan` package, using a subset of the
publicly available dataset “tma” from Item Response Warehouse.
